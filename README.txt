Café de Palma website (cafedepalma.ae)

Upload the contents of this folder to the web root of cafedepalma.ae.
Each page is a folder with an index.html (e.g. /menu/, /festive/), so the clean URLs
work on any standard web host without rewrite rules. All links are root-relative (/assets/...),
so the site must be served from the domain root, not a subfolder.

Included: Google Analytics G-DMEMDRD51P (all pages), Google Tag Manager GTM-M4FKT5CL
(loads on cafedepalma.ae only), sitemap.xml, robots.txt, site.webmanifest.
After going live: submit https://cafedepalma.ae/sitemap.xml in Google Search Console.
Seasonal content hides itself automatically (Halloween after 31 Oct, festive after 31 Dec 2026).
